# 회사·집 PC 설정

## 설치 파일로 바로 실행

1. [최신 Windows 릴리스](https://github.com/aijunny0604-alt/directors-lab/releases/latest)에서 `Directors-Lab-Setup-…-x64.exe`를 내려받아 설치합니다.
2. `Directors Lab`을 실행합니다. Electron 실행 환경이 포함되어 Node.js·Python 설치가 필요 없습니다.
3. **ChatGPT 연결 → Continue with ChatGPT**에서 기존 계정으로 로그인하고 플랜 사용에 동의합니다. 첫 연결 후 모델은 해당 계정 목록에서 자동 선택되며 변경한 선택값도 기억합니다.
4. **연결 테스트 (AI 1회)**를 실행합니다. `실제 스트리밍 연결 테스트 통과`를 확인합니다. 플랜 사용 한도를 소비하며 별도 API 키를 요구하지 않습니다.

집 PC에서도 같은 설치 파일로 1~4단계를 한 번 진행하세요. 각 PC의 Windows 계정으로 인증정보를 암호화하므로 회사 PC의 로그인 폴더는 복사하지 않습니다.

## 작업을 자동으로 이어가기

1. 두 PC에 [Google Drive 데스크톱](https://support.google.com/drive/answer/10838124?hl=ko)을 설치하고 같은 Google 계정으로 로그인합니다.
2. 회사 PC에서 앱의 **기기 동기화 → Google Drive 폴더 선택**으로 개인 Drive 폴더를 고릅니다. 앱이 `DirectorsLab-sync` 하위 폴더를 준비합니다.
3. 집 PC에서도 같은 Drive의 같은 폴더 또는 `DirectorsLab-sync` 폴더를 고릅니다.
4. Drive 폴더는 오프라인 사용 가능으로 설정하고, 다른 PC로 이동하기 전 **지금 동기화** 및 Drive 업로드 완료를 확인합니다.

보드·프로젝트·AI 결과·실행 로그·선택한 모델·첨부파일은 주기적으로 확인합니다. 동시에 수정하면 두 버전을 보존하고 사용할 버전을 선택하게 합니다. Google Drive가 미설치·미로그인·오프라인이면 다른 PC까지 전달되지 않습니다. 이 PC 로컬 기록은 유지합니다.

## 기존 웹사이트 자료 가져오기

웹사이트 **백업 → JSON 백업 내려받기**, Windows 앱 **백업 → JSON 파일 복원** 순서로 옮깁니다. 원본 에셋 파일은 웹사이트의 에셋 관리실에서 별도로 백업한 뒤 앱으로 가져옵니다. 웹사이트 브라우저의 이후 수정은 앱의 Drive 동기화와 별개입니다.

## 자동으로 반영되는 것

- 앱 시작 때 이 저장소의 최신 스튜디오 원본을 확인하고, 호환 검사 통과 시 고정 커밋의 원본을 적용합니다.
- 로그인 토큰 갱신·모델 목록 확인·모델 선택 기억은 앱이 처리합니다.
- 한 번 선택한 Drive 폴더는 이후 실행에도 유지하며 주기적으로 변경을 확인합니다.
- 네트워크 오류·잘못된 업데이트·동시 수정으로 기존 자료를 자동 덮어쓰지 않습니다.

최신 원본 적용은 앱을 다시 실행하면 확인합니다. Windows 연결 프로그램 자체의 새 버전은 최신 릴리스 설치 파일로 갱신합니다. 인증 승인은 각 PC의 사용자에게 있으며 계정 비밀번호나 토큰을 GitHub에 등록할 필요가 없습니다.
